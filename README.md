# ✨ AuraWrite | 專屬您的極致美學寫作空間

一個兼具高雅視覺設計與流暢編寫體驗的個人寫作系統。結合了心情追蹤、多媒體區塊排版、智慧地理定位，並支援 **PWA 離線寫作**與 **Supabase 雲端資料同步**，讓您不論在何處、何種網絡狀態下，都能優雅地記錄生命中的點滴。

---

## 🌟 核心特色

### 1. 極致美學視覺設計
* 精心調配的深色（Dark Mode）與淺色（Light Mode）模式，帶有霓虹微光與毛玻璃（Glassmorphism）層次感。
* 動態心情圖表與圓環比例圖，用色彩與光影具象化您的情緒流動。

### 2. Notion 風格多媒體混合排版
* 靈活的區塊化（Blocks）編輯器，可自由新增、上下移動、刪除不同的內容區塊：
  * **文字段落**：支援自動增高與智慧游標防跳動。
  * **影像區塊**：支援圖片上傳與自訂圖片說明。
  * **影音區塊**：支援影片播放。
  * **錄音區塊**：支援本機麥克風直接錄音，並帶有專屬的時裝播放器。
  * **外部連結**：自動抓取網頁標題、簡介與預覽圖，生成高質感的書籤卡片。

### 3. 智慧心情與自訂分類
* 支援多種心情狀態複選，並能**自由新增與刪除自訂心情**（同步至雲端）。
* notion 風格的分類管理，支援動態下拉選單、文章篇數自動計算。

### 4. 📍 地理位置與足跡記錄
* 自動透過瀏覽器獲取當前經緯度，並轉譯為實際地址。
* 重新設計的防重疊標籤外觀，精美呈現您的足跡。

### 5. ✈️ 100% 離線寫作與雲端同步 (PWA)
* 透過 Service Worker 技術，在**完全無訊號、無網路（如飛機上或地下室）**時也能秒開網頁進行寫作，資料會先安全地儲存在本機的 IndexedDB。
* 當重新連上網路時，系統會在背景**自動將資料同步上傳至 Supabase 雲端資料庫**。

---

## 🛠️ 技術架構

* **前端核心**：HTML5 / Vanilla CSS3 (原生 CSS 變數) / Vanilla JS (ES Modules)
* **雲端資料庫**：Supabase (PostgreSQL / Authentication / Storage)
* **本機資料庫**：IndexedDB (本機快取與離線寫作)
* **圖標庫**：Lucide Icons
* **字體系統**：Google Fonts (Outfit & Inter)

---

## 🚀 專案運行與同步

### 本機測試與執行
雙擊執行資料夾中的 **`AuraWrite-Start.command`**：
* 系統會在背景開啟本機伺服器。
* 提供本機預覽連結：`http://localhost:8001`。

### 雲端一鍵同步上傳
當有任何功能優化或代碼更新時，雙擊執行桌面的 **`AuraWrite-Push.command`**：
* 系統會自動打包所有更新檔案，並一鍵推送（`git push`）至您的 GitHub 倉庫。
* GitHub Pages 將會在 1 分鐘內自動重新發布更新，您的專屬網址隨即套用最新版！
